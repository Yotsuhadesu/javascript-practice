# JavaScript Practice - Day 3
## Conditional Statements
- executes the first block whose condition is met and skips the other blocks
1. if statement
    - executes a block of code if a condition is true, otherwise, skip
    - Format:

            if (condition) {
                // code statement
            }
2. if else 
    - Format:

            if (condition) {
                // code statement
            } else {
                // code statement
            }
3. if else if
    - Format:

            if (condition) {
                // code statement
            } else if (condition) {
                // code statement
            } else {
                // code statement
            }
## Iterative Statements
- executes the code inside the block as long as the condition is true
1. for loop
    - Format:

            for (initialization; condition; update) {
                // code statement
            }
2. while loop
    - Format:

            while(condition) {
                // code statement, update statement
            }
