# JavaScript Practice - Day 2
## Arithmetic and Assignment Operators
- `+` - addition
- `-` - subtraction
- `/` - division
- `*` - multiplication
- `%` - modulo (gives the remainder)
- `=` - assigns a value
- `++`/`--` - adds or subtracts 1
- `+=` - shorthand way of adding and then assigning that value, same with `*=` and etc.
## Relational Operators
- returns true or false
- `==`/`!=` - compares the converted values if they are/are not equal
- `===`/`!==` - checks the data type of the values and compares them if they are/are not equal
- `>` - greater than
- `<` - less than
- `>=` - greater than or equal
- `<=` - less than or equal
## Logical Operators
- returns true or false
- `!` (NOT) - reverses the boolean value
- `&&` (AND) - returns false if there is a false value
- `||` (OR) - returns true if there is a true value
## String Concatenation
- `+` - concatenates strings
## Commands Learned
- `prompt()` - asks the user for a value and always returns a string or null on `Cancel`
- `confirm()` - returns true if `OK` is clicked and false if `Cancel` is clicked
- `alert()` - shows a pop-up message
- `console.log()` - logs a value in the console
- `,` - passes the real value in the console
- `Number()` - evaluates and turns a value into a number
- `typeof` - shows the data type of a value
- `textContent` - shows raw plain text
- `innerHTML` - shows HTML elements and text
- `document.getElementById()`
    - document represents the HTML page in the browser and getElementById finds the specific element in that page
